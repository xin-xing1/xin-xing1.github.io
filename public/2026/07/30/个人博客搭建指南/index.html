个人博客搭建指南

Hexo 静态博客 + GitHub Pages

1.注册 GitHub 账号

访问 https://github.com/ 注册，用户名设置为 xin-xing1

2. 安装 Git（代码上传工具）

  1. 官网下载：https://git-scm.com/downloads
  2. Windows 安装全程默认，勾选「Add Git to PATH」；Mac 直接 brew 安装

3. 安装 Node.js（Hexo 运行依赖）

  1. 官网下载 LTS 长期支持版：https://nodejs.org/
  2. 一路默认安装

4. 配置 Git 全局账号（绑定 GitHub）

终端执行，替换为你自己的 GitHub 信息：

5. 全局安装 Hexo

6. 创建博客文件夹并初始化

GitHub 创建专属 Pages 仓库

  1. GitHub 右上角 New repository 新建仓库
  2. **仓库名称强制填写：xin-xing1.github.io**（大小写严格匹配用户名）
  3. 仓库权限选 Public，不要勾选 Add README、license 等初始化选项，创建空仓库。

① 站点基础信息（顶部）

五、一键部署上线（访问 https://xin-xing1.github.io）

部署三连命令（清理缓存→生成静态文件→推送 GitHub）

bash

执行完成提示 INFO Deploy done: git 代表部署成功。

开启 GitHub Pages 服务

  1. 打开仓库页面 → Settings → 找到 Pages

  2. Build and deployment：

    • Source：Deploy from a branch
    • Branch：选择 gh-pages，文件夹选 /root

  3. 保存，等待 1~3 分钟生效，访问 https://xin-xing1.github.io 即可打开博客。
